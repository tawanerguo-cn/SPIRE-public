# 扫描行时间与状态

## 扫速怎么选

按扫描宽度、正反向行时间和实际跟踪选速度。频繁刮擦先减速，观察连续正反线是否改善；
短图只减少行数，不要求每行扫快。具体判断见[扫描策略](../tip_conditioning/workflow.md#扫描速度怎么调)。

## 扫速纹理与时间伪影

若周期纹理在 forward 与 backward 扫描间改变方向，这可以支持“时间变化成分”而非静态表面周期的假设，但不能直接判为反馈振荡或某个确定共振。可在同一区域、保持其他条件可比时改变扫描速度，按实际扫描速度把空间周期换算成候选时间尺度；再核对采样率、行同步、混叠、漂移和非刚性差异。一次历史 Au(111) 观察没有测量传递函数，仍保留这些竞争解释，因此只把方向和扫速对照当作诊断线索，不据此确定噪声源或调整通用阈值。

## 设置值与回读不一致

- 行时间可能被仪器离散化。设备一在 256 像素、20 nm、保持行时间模式下，请求 0.300 s 曾回读 0.2944 s；0.320 s 回读匹配。
- 0.320 s 是该配置可接受的设置值，不是推荐扫速。改变像素数、采样设置或软件后重新核对。
- 设置报错时，先读实际 frame、speed 和扫描状态，再决定下一步；不把差值一律当浮点误差。
- 上述数据与 12.8 ms 步长相容，但完整取整规则未知，不能据此给所有设置自动取整。

## 起扫

Start 返回与开始扫描可能有延迟。用实际 running 状态确认起扫，再检查新数据；
不要因为第一次回读仍为 stopped 就重复发送 Start。
