# 测谱与频谱：先核对条件，再判断结果

## 测谱前

- 核对实际偏压轴、工作点、反馈 HOLD、Reset Bias、扫向、点数和锁相设置。
- 按当前信号目录核对通道名和单位，不照抄另一台仪器的编号。
- Linear 模式不需要 MLS 专用配置；不为查询而切换测量模式。
- 锁相调制幅度使用所选信号的单位；Modulator 编号不等于频率寄存器编号。
- 核对调制源、解调输入、双方频率绑定/谐波/相位、HP/LP及同步滤波、实际X/Y或R/φ输出；通道名不能代替模式回读。滤波响应要与等待/积分时间相配，幅值的峰值/RMS及增益未标定时不换算绝对电导。
- Lock-in Run=OFF不关闭已经运行的调制器；谱前/后读到调制器OFF，也不证明谱内没有调制。

## 遇到这些回读

| 现象 | 怎么处理 |
| --- | --- |
| 通道名称缺失、配置解析失败 | 核对本站协议版本与信号映射，未确认前不拿旧编号启动谱 |
| Modulator 返回 phase register 0 | 保留未知，查实际绑定；不自动加 1 或猜频率 |
| 最大 slew 为 Infinity | 不能作为有限速率 recipe 的输入 |
| 返回的首列是 Bias calc | 用实际返回的偏压轴解释谱，不按请求通道数量盲目切数组 |
| 未记录 final Z，末尾固定参数为 NaN | 与测量数组分开判断，不等同于整条谱无效 |

## 测谱后

看采集过程中是否限幅、跳变或失真，再检查所需重复性。测后电流恢复不代表刚取得的谱可用。
恢复前被退针截断的记录，不能用来推算自然恢复时间。
Au谱缺少表面态起始或背景异常时，先看原始I–V、X/Y、固定Z、扫向/时序及不同位置；保留针态、局域样品与测量链的竞争解释，不仅凭差谱加重修针。

如果测谱时的回读表明 Z 处于 HOLD，那么该时段的电流时间波动不能仅用快轴扫描或正在工作的 Z 反馈环解释；但固定的 Z 命令值不是物理隧穿间隙的独立测量。结电导/势垒变化、真实间隙运动、偏压或前置放大器噪声及锁相采集仍可能解释谱形，必须保留为竞争假设，不从 HOLD 单独推出原因。

只读诊断用[现有接口](../../../docs/operations/authorized-control.md#锁相诊断接口)；未解析字段保留未知，不能拿部分成功当作测量链已验收。

## Spectrum Analyzer

FFT 频谱与 Bias Spectroscopy 的 I–V / dI/dV 是不同数据。
核对频轴起点、间隔和单位；平均模式为 None 时，设置中的平均次数不代表做过平均。
绝对归一化未核实时，不把幅值直接当作标定噪声密度。
约 20 ms 间隔的 I/X/Y/Z 轮询是受采样率限制的时域序列，不是高带宽波形或 Spectrum Analyzer 轨迹。不能从它重建高于轮询带宽的尖峰，也不能把时域 RMS 直接等同于频谱积分功率；比较时还要分别核对 Analyzer 的 RBW、频率范围、单位、平均方式和归一化。这里的采样间隔来自一组历史对照，不代表所有采集配置。
