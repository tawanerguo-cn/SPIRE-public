# Home、Withdraw 与恢复

## Home、Withdraw 与重新开反馈

- **Home**：Z 回到配置的 Home 位置（Absolute / Relative），不一定完全退针。
- **Home 后恢复工作点**：本站通常比 Withdraw 后重开 controller 少等待；若电流与Z已稳定即可继续，不能把“用了Home”代替恢复检查。
- **Withdraw**：关闭 controller，Z 压电收至上限，粗马达不动。
- **Withdraw 后重开 controller**：先等 Z 的持续漂移明显收敛、电流稳定，再扫描、测谱或修针。按实际恢复判断，不固定等几秒。
  电流已经安静时，Z仍可能在缓慢恢复；用连续时段确认趋稳，不用一次读数或被提前中止的窗口推算自然恢复时间。

## pulse / poke 后

- 动作时电流尖峰、顶量程与恢复后的针态分开看；不能仅凭单点尖峰退针。
- 等恢复后比较电流偏差和波动；仍在变化就继续观察，稳定后再判断是否改善、是否够用。
