# 扫描探针 agent：可借鉴的方法

## quailbot

在 4 K FeTe / 钨针 STM 上，专家教学后的 LLM 结合仪器能力、动作关联回读和日志完成修针；
论文报告两次 launch-only 交付，由专家结合图像、FFT 和 BraggZ 核查。

| 方法 | 对实验协作的意义 |
| --- | --- |
| 按任务装入知识和技能 | 先给索引，需要时再读全文，减少无关材料 |
| 动作结果与关联读数一起返回 | 同时知道做了什么、状态怎样变化、还缺什么 |
| 扫描尚未完成时读取局部形貌 | 发现突起或杂物便重新判断位置与后续动作，不把原计划坚持到整帧结束 |
| 预期干净区域仍出现杂物时调整换区策略 | 检验区域假设；重复修针不能替代寻找可用表面 |
| 近期结果详细、较早结果精简 | 保留当前判断需要的上下文，原始证据另存 |
| 修改记忆前核对旧内容 | 避免用陈旧摘要覆盖更新 |
| 必要时向人工交接 | 弯针、样品问题或粗动卡滞可能需要信息或物理处理 |

上下文和日志机制已核对固定源码；局部扫图与换区例子来自论文 Results 和图 2，未运行复现。两次成功不足以估计跨样品成功率；
初末工作点不同，分数变化不能全归因于针尖。BraggZ 是晶格峰对比指标，成像终点也不等于 STS/ESR 合格。

## AIMS

AIMS 用 MCP 组织定位、测量选择和解释三个循环，在 Nanonis 控制的低温 MIM 上工作。
其方法提示：先明确当前问题和缺少的观测，再选能区分候选解释的测量；定位不确定度、数据有效性和物理推断分别处理。

论文报告导航耗时约从 10 小时缩至 4 小时，但人工选点对照的针尖条件不同。
GP 重建区分实测与预测像素，高温结果中的外推与直接测量分开解释。
研究者提供问题、先验和恢复提示；不能把流程图中的人工路径算成 agent 自主控制。

## 怎样用于本站

- 优先让知识、工具结果和上下文回答当前实验问题，避免把全部历史装入每轮输入。
- 用同一任务、可比条件和独立复测比较效果：完成率、耗时、无效/恶化干预及人工投入。
- 保留失败和需要人工帮助的情形；仅接入 LLM、MCP 或日志并不构成新的实验成果。

AIMS 的 SI 与运行代码、quailbot 的完整原始实验数据尚未在既有阅读中取得；不据此声称完整复现。
论文、固定代码版本及阅读范围见[目录](catalog.toml)，SPiRE 的开发方案放在[研究设计](../../../../docs/research/agentic-spm-design.md)。
