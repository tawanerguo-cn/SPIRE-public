# 自动修针：方法与适用条件

## 先明确要修到什么程度

成像、STS/ESR 和功能化针尖各有目标。图像清楚不保证谱可用；CO 功能化还要检查功能化状态，
不能用一个“好针”分数代替所有用途。本站动作选择见[修针策略](../../tip_conditioning/workflow.md)。

## 可以借鉴的方法

| 方法 | 适合解决什么 | 使用条件 |
| --- | --- | --- |
| 已知缺陷参照、多观察点投票（Rashidi / Wolkow） | 减少局部样品结构造成的误判 | 参照缺陷及成像条件能比较 |
| 滚动扫描线窗口（Gordon 等） | 在图尚未扫完时识别针态变化 | 连续线迹已经包含判断所需特征；短窗口不等于高扫速 |
| 区域、接触与针态分开判断（DeepSPM） | 避免把坏区域或采集问题都当成坏针 | 同时看图像有效性和仪器信号 |
| 干净 Au 区域与参考 dI/dV（Wang 等） | 判断是否适合 STS | 保持可比结条件，按谱学目标验收 |
| 独立干净参考金属（Scanbot） | 将修针损伤与科学目标区分开 | 设备和样品布局允许可靠返回 |
| 模板匹配、确定性谱指标（Barker 等） | 标注数据少时建立可解释判断 | 参照与当前任务匹配，保留未知类别 |
| 专门的功能化验证（Alldritt 等） | 判断 CO 等功能化是否成功 | 使用该功能化状态的图像及对称性标准 |

## 怎样判断策略是否有效

动作后看目标是否改善，达到用途就停止。短时信号改善、形貌改善和谱学可用分别评价。
比较策略时同时记录成功、无改善和恶化；按针态及实验批次分组，避免相邻片段同时进入训练和验证。

方法不能因换一个样品就直接沿用原阈值。模型输出需要与本站图谱核对，论文中的动作列表不替代操作员的现行策略。
