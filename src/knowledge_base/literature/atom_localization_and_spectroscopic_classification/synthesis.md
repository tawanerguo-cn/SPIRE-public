# 原子定位与逐点谱学分类

## 从图像候选到物理类别

形貌受几何、电子态、偏压、设定电流和针尖共同影响。亮点先记为候选；
有对应谱学依据后，再区分 TiO、TiB、Fe 或当前实验定义的类别。证据不足保留 unknown。

| 观察或任务 | 怎样处理 | 检查什么 |
| --- | --- | --- |
| 图中寻找孤立目标 | 从原始浮点通道校正背景，用局部极值、轮廓或尺度滤波生成候选 | 台阶、颗粒、反馈条纹和边界是否被误识别 |
| 两个目标粘连 | 多阈值或分水岭尝试分离，分不开就记模糊候选 | 中心位置、邻距和局部背景是否支持两个目标 |
| 准备按候选坐标测谱 | 将原始像素经过方向、裁剪、旋转和 frame 变换映射到物理坐标 | 显示图与原始数组坐标是否一致 |
| 顺序测多个目标 | 结合坐标年龄、漂移趋势和定位精度判断是否需重定位 | 用稳定锚点或局部图相关更新偏移 |
| 某条谱明显异常 | 先核对落点、限幅、缺点、跳变和针态变化 | 异常数据不要直接用于物种分类 |
| 图像与谱的类别冲突 | 保留冲突，补能区分解释的证据 | 不用形貌先验盖过谱学结果 |

一组历史图像评审还暴露了简单全局 MAD 候选基线的两种失败：台阶或宽背景变化会让局部特征漏检；最小候选间隔设得过小又会把一个宽特征重复计数。保留 partial-scan mask，先看 raw 正反图，再在局部背景和 ROI 下复核；检测器的 score 不是校准概率，候选数量也不是原子数。这些是一个扫描集和一个基线算法的限制，不构成对所有表面或模型的性能保证。

测谱时保留原始偏压轴、单次及正反向 sweep，核对工作点、锁相和处理条件。
峰、台阶、对称性、背景和重复性按当前类别参照比较。离线图像去漂移不等于仪器已经补偿。

## 方法对照

| 工作 | 可借鉴点 | 适用限制 |
| --- | --- | --- |
| Lafleur / Phark | 方向校正、去平面、轮廓筛选、粘连分离，再逐点 STS 分类 | 形貌模型约 86% 验证准确率；小谱集的 100% 不能当本站成功率 |
| Diao 等 | 图像有效性、吸附体检测、原子位点定位分别建模；连续图匹配漂移 | 候选存在不等于精确落点仍有效 |
| Thomas 等 | 采谱间隔中重采局部图、相关校正；谱分类与主动选点 | 长任务不能只靠最初一张图 |
| unDrift | 利用方向、角度和栅格时序做图像配准 | 校正图仍需保留原始坐标和变换 |
| Barker / Sweetman | 数据少时使用确定性谱指纹，并与后续模型比较 | 保留拒判，验证集按 session、针态或日期划分 |

评价定位方法时看漏检、误检、位置误差和模糊候选；评价谱分类时看独立批次的结果与拒判，
不只看一个 accuracy。谱学分类结果连同当时位置和针态保存，后续漂移校正不改写旧测量的坐标。
