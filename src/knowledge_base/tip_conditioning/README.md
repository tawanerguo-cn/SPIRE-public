# STM 修针与样品验收

[修针流程](workflow.md)给出观察、判断与下一步动作；[评分规则](quality_rating.md)分别评价信号、成像和谱学，仅组合本次实验用途所需的项目。结构化数值和历史参照见[修针经验](local_experience.toml)及下表所列条目。

## 共用的诊断规则

先按后续实验目标选验收项目。只做成像时，不要求谱学通过；要测谱时，再检查对应材料的谱学特征。若需要小戳诊断，四种材料共用以下形貌判断：比较相近戳深、工作点和像素尺度下的**表观半径、圆度、紧凑单叶形状、正反扫对应及当前电流稳定性**。戳痕应相对邻近背景抬起，不应留下可辨的真实凹陷；接近零的噪声负像素本身不算凹陷。评估完整戳痕，不能只挑最圆的主峰；轻微拉长未必需要继续修，但分裂、多叶或拖尾需结合整幅正反图判断。这里量的是表面戳痕的表观尺寸，不是针尖顶端的直接几何尺寸。

## 按材料选择目标与历史参照

以下数值和等级均是原安装环境的历史观察。评分采用人工 0–3 级，尚未校准为通用指标或自动通过线；它们用于说明特定材料、测量用途和覆盖范围，不构成别的站点的默认阈值。

| 材料 | 成像与谱学重点 | 已记录的历史结果及覆盖边界 |
| --- | --- | --- |
| Au(111) | 未操作背景的鱼骨条带、转折与正反扫对应；谱学关注约 −0.5 eV 的表面态起始，先核实仪器偏压约定。原子分辨按实验用途另验。 | 一种针态的鱼骨与表面态被评为基本可用、非最佳（整体 1），仍有残余噪声。另一个独立用途参照中，原子成像评为 3、谱学评为 0；约 0.29 nm 周期可辨，但慢扫存在畸变，不作原子位置计量标准。见 [Au(111) 条目](au111_reference.toml)。 |
| Ag(111) | 修针位置看紧凑、近圆、单叶形貌及 Z 正反扫回程；背景按目标另验。谱学可将本站约 −68 mV 的 dI/dV 起始与公开 Ag(111) 表面态位置对照。 | 一次优秀参照为短图和单条谱，人工等级 3；图只采到 256 行中的 19 行，谱为单次 sweep。该谱的台阶/去趋势噪声比约 41，戳痕等效表观半径约 1.27 nm；这既不是完整面积图，也不证明重复性或真实针尖半径。见 [Ag(111) 条目](../tip_quality_references/ag111_short_scan_reference.toml)。 |
| Pb(100) | 图像按用途检查台阶、背景或目标结构及正反扫对应。谱学需核实温度、磁场、RF、偏压零点、调制和针态，再看双侧能隙形状、峰/背景、重复性；区分普通针与覆 Pb 针，不以单个峰电压或有效温度拟合判定针态。 | 第一组 TF 前图谱被接受为样品参照，整体等级 2；覆盖为部分短图、平均谱和两次 sweep，未拟合能隙。第二组未获认可。条件仍有未知，不能据此定量能隙或确定超导针态。见 [Pb(100) 条目](pb100_reference.toml)。 |
| Ag(100) | 比较来回扫噪声、电流噪声及本次目标结构；小戳只在诊断需要时做。谱形、背景和重复性与同材料参照比较。 | 一种日间针态由操作员评为信号、成像噪声和谱学各 3 分；原生谱文件及其采集条件未绑定，另有 73 个连续 10 s 观察窗口的 RMS 约 0.303–0.447 pA，但扫描位置在变，因此这不是固定等待时长或验收线。另一个“够用”形貌参照只认可最后一次戳后的区域，轮廓被停扫/重启高度突变截断，半径和圆度未定量。见 [Ag(100) 条目](ag100_reference.toml)。 |

这些历史参照的原始图像、谱、运行日志和审计包未随公开仓库发布，摘要不能从当前 checkout 独立复现。材料、针态或关键测量条件变化后应重新评审；不为补做无关项目或凑齐小戳而改变已达到目标的针态。换工作点、扫描尺度或采集条件比较结果时，先保证条件可比。

仪器局部设置见[仪器配置](../instrument_profiles/README.md)；真实操作仍受 typed interface、`SafetyGate` 和本站已批准的操作范围约束。
