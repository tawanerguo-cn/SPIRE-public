# STM 修针

接续已有尝试，修到本次实验够用就保留针态。验收看[质量与材料参照](quality_rating.md)，本站结构化数值和观察见[经验记录](local_experience.toml)。该记录只代表原安装环境，且其来源数据未随本仓库发布；其他实验室应先核对仪器配置与自身验收要求。具体动作始终受代码中的 typed interface 与 `SafetyGate` 限制。

## 先确定后续实验需要什么

先明确后续实验的目标、工作点和是否测谱，再判断当前针态缺什么。只做成像，就看目标分辨、正反扫和信号；需要测谱，再加对应材料的谱学验收。评价成像用途时，不能因为一个无关的谱学项目较差而继续修针。历史 Au(111) 参照中，原子成像优秀与谱学不可用同时成立；只有后续目标需要测谱时，才按材料目标另验谱，参照及其覆盖限制见[材料条目](README.md#按材料选择目标与历史参照)。

## 从当前结果决定下一步

| 当前表现 | 判断与下一步 |
| --- | --- |
| 开始几行 raw 和减线性拟合图已显示大片颗粒、团块或杂乱地形 | 先换区域；不能从杂乱大图里截一个较平滑小块就认为已找到干净修针区 |
| 可辨认规整台阶，台阶间平台整体平滑 | 这是可用的平坦地形；在平台内选点，避开台阶边缘和旧损伤 |
| 干净平台仍有细小背景起伏 | 皮米级平整不等于无噪声；按实际高度标尺、电流稳定性和目标清晰度判断，够用就保留 |
| 偶尔刮一下，随后正常 | 继续观察；频繁刮则先减速 |
| 减速后仍在多处拖尾、重影或不稳 | 结合未操作背景和停针电流，区分针态与反馈问题 |
| 恢复后的电流稳定，改善能保持，已接近本次用途 | 保留候选，用局部扫图检查，仍需形貌诊断时再小戳 |
| 当前用途所需项目已获优秀认可 | 保留针态，不为补测无关项目或补戳改变好针态 |
| 电流稳定但图像仍差 | 结合干净背景、跟踪和小戳半径、圆度判断；确有针态缺陷时继续修整 |
| 同一针态下完整戳痕确有分裂、多叶或拖尾 | 仍未修好；不能只看圆的主峰。先排除扫到旧痕及扫描中途突变，再决定小戳精修 |
| 小戳轮廓较圆，但戳痕仍有可辨的、低于周围背景的凹陷 | 仍有部分未被抬起，针态还不好，继续小戳精修 |
| 成像已满足用途，谱差但后续不测谱 | 结束修针，保留成像针态；谱学结论单独记录 |
| 后续需要测谱，形貌够用但谱差 | 保留候选，先核对局域样品、锁相、时序和噪声，再判断是否需要修整 |
| 原位 pulse 效果不好或变差 | 可能已打坏局部表面，换干净点继续 pulse |
| 不同干净位置的 pulse 仍达不到要求 | 可考虑深 poke 重整；改善后回到轻动作 |
| 多种方法和位置均无有效进展，或需要物理处理 | 带当前状态和已尝试结果请求人工帮助 |

## 扫图策略

通常选择正方形扫图区域，非必要不使用其他比例；使用其他比例时，XY 像素比例必须与扫描区域匹配。
**扫图时间视噪声需求而定，兼顾效率和准确度。** 不盲目调大，也不盲目压缩。

| 用途 | 扫描范围 | 常用整帧时间与判断 |
| --- | --- | --- |
| 大范围形貌观看 | 100–500 nm，常用 100、200 nm | 通常大于 10 min |
| 常规用图 | 30–100 nm | 一般 5–15 min；针尖较差时 poke 尺度可能很大，不能过分缩小。也用于看台阶锐度和扫图噪声的波动水平 |
| 小图 | 5–30 nm | 一般 5–10 min；看较好针尖的小戳效果、原子分辨或其他精细结构。原子分辨很难看到 |

选区先看足够宽的地形，让平台、台阶和杂物分布可辨。raw 看整体起伏，减线性拟合看坡度下面的结构；规整台阶间的平滑台面可用于修针，连续斜面本身也不等于杂乱。
开头有效几行已显示杂乱时即可移框或换区；视野里仍只有成片团块，就扩大范围继续找。找到可用台面后，再按当前缺陷和噪声选择局部图的范围与时间，已有连续图像足够判断就决定下一步。
可用保存扫描的离线平整度分析辅助选区，结合原始正反图检查平台内部及计划扫描经过的位置；分析候选须由操作者复核。
自动色标会放大皮米量级的纹理，先看实际高度范围，再看条纹、跳线是否妨碍目标。平坦背景主要是噪声时，正反扫相关性低也可以很好；台阶和戳痕则要看结构是否对应。
很好的背景图是改善参照；很多时候达不到同样低的噪声，只要当前电流稳定、目标可辨，仍可以够用。

### 扫描速度怎么调

在干净区域看刮擦频率和正反扫跟踪。频繁刮就减速，在同一张图上看后续连续线段；仍频繁就继续调。
同样行时间下，扫描越宽走得越快。比较时尽量保持位置、尺度和工作点，看原始正反线与电流尖峰、高度突跳的对应。
连续扫描中若从某行起突然改变，同时电流或 Z 异常，按时间分段复核；前后图对应不同结状态的可能性，不能把后段条纹一概当作固定戳痕的尾巴。
短图可以少扫几行，但别把每行扫快、反复启停当成快检。减速改善后先验收当前针态。

## 动作怎样选

**pulse 是常规修针动作，连续打几十至几百次很正常。按效果决定继续、换点和检验。**
通常沿用选定的标准幅度和时长，节奏随实际恢复调整：恢复快就接下一发，仍在变化就继续观察。恢复后电流仍不稳就继续修；原位效果差或变差，换干净点继续。
改善能保持时转入当前用途所需检验，以电流、图谱及按需取得的戳痕证据决定是否收手。修整效果可能反复，短暂安静只是检验候选；继续、换点或保留都看本轮结果。
下表按本站经验由轻到重排列，按针态选，不必逐级做。

| 动作 | 参数与用途 |
| --- | --- |
| 小幅 poke | 约 1 nm 或更小，通常不超过 2 nm；适合常规修整和精修。每次用新平坦点，保持工作偏压、等幅返回并恢复反馈 |
| 标准 pulse | 通常 ±10 V，明确极性和时长；常规修整 |
| 深 poke | 5 nm 及以上；pulse 在不同干净位置仍不理想时可重整，改善后回到轻动作 |

本站还有 50 nm 深戳和常用 200 ms pulse 的经验；执行范围查控制说明。poke 深度指控制行程。

## pulse 的验收参考

**恢复后的电流稳定性是核心。** 比较同一位置、工作点下紧邻的前后窗口，并看改善能否保持。

| 看什么 | 怎样判断 |
| --- | --- |
| 电流偏差、波动和跳变 | 恢复后接近设定值、波动减小且能稳住，是主要改善依据；同时看相对变化和当前是否够用 |
| 动作中的电流峰值 | 约 +10 nA 或 −10 nA 可作有效响应线索；恢复后的电流表现决定是否保留。漏采或削顶时保留峰值未知 |
| 恢复后的 Z | 同位置、工作点下 Z 变小可作辅助线索；Z 变小而电流变差不算改善 |

这些是综合参考，按电流表现和当前用途取舍。比前窗略差但已够用也可以保留；一次短暂安静后又反复跳变，就继续修整。
电流阈值反复穿越本身不能证明发生了人工 pulse。一个历史扫描序列中，电流尖峰以接近逐行扫描周期的间隔出现；在归因前，应对齐 scan 状态、XY 运动、Z 轨迹和有来源的命令事件。这个时间相关性只提示扫描同步伪影的可能，不能单独识别其物理机制或证明某次人工动作。

## 干净位置与阶段性检验

在已看清的台面内选新点，根据旧痕的完整轮廓、拉起范围和拖尾安排新点与扫描窗口，使新旧戳痕可分辨。一张宽图可以支持多次局部选点，稍移到旁边空白平台即可；扫图不必始终以戳点居中。

原位 pulse 效果差时，可在扫描器范围内移到另一个干净、未操作点，确认到位、电流和 Z 稳定后继续。
局部换点无需粗动退针，也无需每发 pulse 都换点。

修整后得到稳定候选，就在损伤区外检查背景和台阶的正反扫对应；仍需形貌诊断时用局部小戳检查针态。观察后续连续图像和电流，看改善是否保持。
**小戳兼有修整和验收作用。** 仅有背景安静、尚不足以判断针态时，结合完整戳痕的表观半径、圆度、紧凑单叶程度及相对背景的抬起，结合正反扫和当前电流判断是否够用。
Au(111)、Ag(111)、Pb(100)、Ag(100) 做小戳诊断时共用这套戳痕标准；后续需要测谱时，才加对应材料的谱学验收。
戳后应相对周围背景抬起来；如果戳痕里仍有可辨的凹下去、没被抬起的部分，即使圆度好也说明针还不好，继续小戳。这里看相对邻近背景的真实凹陷，零附近的噪声负像素不算。
比较相近戳深、工作点和像素尺度下的形貌；半径可用同一轮廓或半高宽的一半比较，圆度结合主轴比、拖尾和分裂判断。这里测的是戳痕表观尺寸。
判断整个戳痕，不能只选最圆的主峰。轻微拉长不必继续追求完美圆形；达到本次已认可参照、抬起且紧凑单叶，电流表现能保持，就保留。
一张图中间有修针动作时，按动作前后分段看；当前针态以最后一次动作后的结果为准。暂停后整行高度突变先对照动作记录，不直接当样品台阶。
一个 Ag(100) 历史“够用”参照只认可最后一次戳后的下方突起及其后的针态；同图中更早的戳痕不代表这个合格状态。停扫后重启时发生的高度突变截断了末次戳痕轮廓，因此半径和圆度都没有可靠定量；达到用途后收手，不要为了补戳改变已够用的针态。操作员认可的日间优秀针态则没有新戳痕，半径/圆度未知且不因此扣分。对应原图和信号未随仓库发布，详见[Ag(100) 材料条目](ag100_reference.toml)；这些事实不能替代现场复核。
已经扫过旧点本身不证明撞针。图像看原始正反扫及目标结构，谱看当前材料的目标特征和重复性。

需要粗动换区时：粗 +Z 退 10 步 → +X 或 +Y 约 450 步（400–500 步）→ Auto Approach。
确认接触后按新区域选框；旧扫描器坐标不代表原表面位置。多处都找不到干净背景时，考虑处理样品。

## 执行节奏与收尾

沿用本轮保存的 pulse、poke 深度和扫描时间；每次明确 poke/移动目标或扫图中心，正方形尺寸只填边长。复用会话参数前核对目标、工作点和本轮授权范围。
小戳恢复后可接局部扫描，无需等整帧。Withdraw 后重开 controller 则先确认 Z 漂移收敛且电流稳定；具体等待条件应按本机控制器和站点 profile 验证。

达到用途就结束修针，保存图谱、位置和动作结果，不为追求更漂亮的戳痕反复改动已够用的针态；操作员接管就交还控制。
