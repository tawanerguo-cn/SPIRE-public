# 针态评分

先明确后续实验用途，再选[本站适用范围内的历史参照](README.md#scope-of-the-references)，评价所需项目。**1 分已够用，达到用途就保留针态。**

## 定量快检

基本检查包括**来回扫噪声、电流噪声，以及需要时的小戳形貌**；本项目历史示例通常用约 1 nm 小戳。谱学按材料和用途评审。已达到当前用途要求的针态可直接保留，具体阈值要由目标站点校准。
调用 `quantify_tip_quality`，最少传材料和原图；按需加已有信号报告、干净背景选区和戳痕选区。读取返回的 `brief`，需要复核时看原图及完整报告。
有台阶、颗粒或戳痕时应指定背景选区；省略选区计算的是全部已采像素，不能直接称为背景噪声。未提供的电流或戳痕指标保持未评；未做小戳不等于已认可的成像、信号或谱学等级缺项。

| 项目 | 工具返回 |
| --- | --- |
| 来回扫 | 正反扫差 RMS、相关性、差值 P95 |
| 电流 | RMS/设定值、设定偏差、尖峰与漂移 |
| 戳痕 | 表观半高宽半径、主轴比、半高单叶/分裂、相对背景最低高度及边缘残差、局部正反扫差 |

配置本样品的差/好参照后换算为 0–100 分，保留各项，总分取最低项。未标定时看实测指标和前后变化，不编合格线。
背景噪声按实际高度、电流及目标是否可辨判断；很好的参照不是每次必达线。平坦背景缺少共有结构，相关性低不能单独判差。
不同样品的结构目标需由对应知识条目给出；目前固定工具已实现上述基础三项，鱼骨/晶格/能隙专项评分待实现。

## 怎么打分

| 分数 | 判断 |
| --- | --- |
| 未评（null） | 缺数据或条件不清 |
| 0：不可用 | 缺陷妨碍本次测量 |
| 1：够用 | 目标可辨，允许噪声和偶发缺陷 |
| 2：良好 | 目标清楚，所需重复检查一致，缺陷少 |
| 3：优秀 | 在本次尺度、条件和覆盖内达到该样品的优秀参照或获得明确优秀评审 |

| 项目 | 看什么 |
| --- | --- |
| 信号 | 恢复后电流偏差、波动、跳变是否妨碍测量；Z 辅助判断 |
| 成像 | 目标结构、正反扫对应、拖尾与重影；戳痕和背景分开看 |
| 谱 | 当前样品的目标谱形、背景和所需重复性 |

## 本次用途决定总分

| 用途 | 总分 |
| --- | --- |
| 成像 | 信号、成像两项的最低分 |
| STS | 信号、谱两项的最低分；需要图像定位时另查成像 |
| 成像和 STS | 三项最低分 |

只做成像时，谱差或未测不降成像用途评价，也不要求补测；成像质量与谱学质量分别评价。
必需项缺测或比较条件未确认，程序合成总分为未评，保留操作员已明确给出的用途评价。图好谱差可以同时成立，各项分数保留。
这些是人工或 agent 的等级判断；程序核验证据并合成总分，尚不能从指标自动判级。

每项只写：**分数 + 一句理由 + 原图谱链接**。记录样品、用途、针态和工作点；换针态或关键条件后重评。
既有材料参照仅保留原认可范围，未提供的数据不得补猜。评分卡格式由 `verify_tip_reference` 工具及其 manifest 定义。

## 修针后形貌参照

小戳的表观半径和圆度是重要参考，同时看紧凑、单叶及正反扫对应；背景看目标结构。表观宽度不等于针尖半径。
四种材料共用戳痕标准。主峰圆但整个戳痕分裂仍不够用；轻微拉长也可以达到已认可的够用水平，不要求完美圆形。图中多次修针时分别评估，当前针态只取最后一次动作后的结果。
戳痕应相对周围背景抬起；仍有可辨凹陷时，即使圆度好也属于针态不足，继续小戳。选区包含完整戳痕、可疑凹陷和干净边缘；最低值需对照背景噪声和原始正反图，不能把一个负像素判成凹陷。
轮廓被扫描中断或选区边界截断时，半径、圆度定量留空，结合原图与电流判断；计算缺项本身不推翻操作员对结果的认可。
材料参照及其缺失数据说明见[范围说明](README.md#scope-of-the-references)；修针前后比较和操作决策见[修针流程](workflow.md)。
